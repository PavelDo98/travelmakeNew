# Памятки для путешественников

## Описание

В приложение TravelOrganizer добавлен новый раздел **"Памятки"** с полезной информацией для путешествий.

## Разделы

### 1. Экстренные службы
Номера телефонов экстренных служб для 12 стран:
- Россия, США, Великобритания, Япония
- Германия, Франция, Италия, Испания
- Китай, Таиланд, ОАЭ, Турция

**Информация включает:**
- Полиция, скорая помощь, пожарная служба
- Единые номера экстренных служб
- Специальные службы (туристическая полиция и т.д.)
- Полезные заметки по каждой стране

### 2. Багаж авиакомпаний
Нормы багажа для 12 авиакомпаний:
- Российские: Аэрофлот, S7, Победа, Utair
- Международные: Emirates, Lufthansa, Turkish Airlines, Air France, Qatar Airways, Singapore Airlines
- Лоукостеры: Ryanair, Wizz Air

**Информация включает:**
- Вес и размеры ручной клади
- Вес регистрируемого багажа (эконом, бизнес, первый класс)
- Важные примечания и особенности

### 3. Советы по странам
Культурные особенности для 12 стран:
- Япония, ОАЭ, Таиланд, Индия, Китай
- США, Франция, Италия, Германия, Испания
- Россия, Бразилия

**Информация включает:**
- ❌ **Что НЕ стоит делать** (запреты и культурные табу)
- ✅ **Что рекомендуется делать** (полезные советы)
- 💡 **Важные заметки** о культуре и традициях

### 4. Общие советы
8 категорий с практическими советами:

#### Подготовка к поездке:
- **Документы** (копии, страховка, сроки)
- **Деньги** (карты, валюта, безопасность)
- **Здоровье** (прививки, аптечка, страховка)
- **Упаковка** (вещи, багаж, организация)

#### В поездке:
- **Безопасность** (ценности, районы, контакты)
- **Связь** (SIM-карты, интернет, карты)
- **В аэропорту** (регистрация, правила, досмотр)
- **Культура** (язык, традиции, этикет)

## Функциональность

### Поиск
- 🔍 Работает по всем разделам одновременно
- Ищет по странам, названиям, текстам советов
- Мгновенная фильтрация результатов
- Подсвечивает совпадения

### Навигация
- 📱 Удобные вкладки для переключения между разделами
- 🔢 Счетчики количества записей
- 🎨 Цветовая кодировка (опасности, рекомендации)
- 📞 Кликабельные телефонные номера

### Дизайн
- Адаптивный дизайн для телефонов и планшетов
- Соответствует стилю приложения (теплые тона)
- Читаемые шрифты и удобные отступы
- Иконки для визуального разделения

## Расположение в приложении

Раздел "Памятки" доступен:
1. Через нижнюю навигационную панель (иконка "ℹ️")
2. Между разделами "Поездки" и "Архив"
3. Доступен без выбора конкретной поездки

## Технические детали

### Файлы
- `js/reference-data.js` — данные памяток (экспортируемый модуль)
- `js/views.js` — функции отображения (reference, renderEmergency, renderAirlines, renderCountries, renderGeneral)
- `styles.css` — стили для памяток

### Структура данных
```javascript
export const travelReference = {
  emergency: [...],      // Экстренные службы
  airlines: [...],       // Авиакомпании
  countryAdvice: [...],  // Советы по странам
  generalTips: [...]     // Общие советы
};
```

## Расширение

Для добавления новой страны или авиакомпании:

1. Откройте `js/reference-data.js`
2. Добавьте запись в соответствующий массив
3. Следуйте существующей структуре
4. Данные автоматически появятся в интерфейсе
