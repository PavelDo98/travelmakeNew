## Как работает

### Автоматическое обновление
1. При `git push` в ветку `main`
2. GitHub Actions автоматически развертывает изменения
3. Обновление занимает **1-2 минуты**
4. Пользователи получат обновление при следующем открытии приложения

### Офлайн-режим
- При первом посещении Service Worker скачивает все файлы
- После этого приложение работает **полностью офлайн**
- Раздел Памятки доступен без интернета
- Обновления применяются автоматически

## Обслуживание

### Обновление данных памяток
1. Открыть `js/reference-data.js`
2. Добавить/изменить данные в нужном массиве
3. Сохранить и закоммитить
4. Изменить `VERSION` в `sw.js` (если нужен форс-апдейт)
5. Push в GitHub
