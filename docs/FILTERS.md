# Фильтры поездок

## Обзор

В приложение добавлена функциональность фильтрации поездок на страницах "Поездки" и "Архив". Пользователи могут фильтровать поездки по году, длительности и количеству участников.

## Доступные фильтры

### 1. Фильтр по году (`year`)
- **Описание**: Показывает только поездки из выбранного года
- **Значения**: Динамически генерируется список всех годов из существующих поездок (2025, 2026, 2027, 2028...)
- **URL параметр**: `?year=2026`
- **Пример**: Выбор "2026" покажет только поездки, начинающиеся в 2026 году

### 2. Фильтр по длительности (`duration`)
- **Описание**: Фильтрует поездки по количеству дней
- **Значения**:
  - `short` - Короткие поездки (до 3 дней включительно)
  - `medium` - Средние поездки (4-7 дней)
  - `long` - Длинные поездки (8+ дней)
- **URL параметр**: `?duration=short`
- **Логика**: Длительность рассчитывается как разница между датами `end` и `start` плюс 1 день

### 3. Фильтр по участникам (`members`)
- **Описание**: Разделяет поездки на сольные и групповые
- **Значения**:
  - `solo` - Соло-поездки (1 участник)
  - `group` - Групповые поездки (2+ участников)
- **URL параметр**: `?members=group`
- **Логика**: Подсчитывается количество элементов в массиве `trip.members`

## UI компоненты

### Раскрывающаяся панель фильтров (`.trips-filter`)
- **Расположение**: Под строкой поиска, перед списком поездок
- **Компоненты**:
  - Summary элемент с иконкой поиска и текстом "Фильтры"
  - Бейдж с количеством активных фильтров (когда есть активные фильтры)
  - Панель с выпадающими списками для каждого фильтра
  - Кнопка "Сбросить фильтры"

### Индикатор активных фильтров
- Показывает количество примененных фильтров в бейдже
- Автоматически скрывается, когда фильтры сброшены
- Панель фильтров автоматически раскрывается при наличии активных фильтров

## Технические детали

### Код фильтрации (`js/views.js`)

```javascript
const filtered = all.filter(t => {
  // Поиск по названию и направлениям
  if (q && !`${t.title} ${t.destinations||''}`.toLocaleLowerCase('ru').includes(q))
    return false;
  
  // Фильтр по году
  if (filterYear && (!t.start || !t.start.startsWith(filterYear)))
    return false;
  
  // Фильтр по длительности
  if (filterDuration) {
    const days = getDuration(t);
    if (filterDuration === 'short' && days > 3) return false;
    if (filterDuration === 'medium' && (days <= 3 || days > 7)) return false;
    if (filterDuration === 'long' && days <= 7) return false;
  }
  
  // Фильтр по участникам
  if (filterMembers) {
    const count = (t.members || []).length || 1;
    if (filterMembers === 'solo' && count !== 1) return false;
    if (filterMembers === 'group' && count <= 1) return false;
  }
  
  return true;
});
```

### Стили (`.trips-filter` в `styles.css`)
- Раскрывающийся элемент с плавной анимацией
- Панель фильтров с мягким фоновым цветом (`var(--soft)`)
- Выпадающие списки с минимальной высотой 48px для доступности
- Адаптивная верстка для мобильных устройств

### Обработчик событий (`js/controller.js`)
```javascript
document.addEventListener('change', e => {
  if (!e.target.matches('[data-filter]')) return;
  const q = new URLSearchParams(route.query);
  const key = e.target.dataset.filter;
  q.set(key, e.target.value);
  navigate(href(route.tripId, route.page, route.id, q));
});
```

## Примеры использования

### Фильтрация по году
```
#/trips?year=2026
#/archive?year=2025
```

### Комбинация фильтров
```
#/trips?year=2026&duration=short
#/archive?year=2027&members=group&duration=long
```

### С поиском
```
#/trips?q=Стамбул&year=2026
#/archive?q=море&duration=short
```

## Поведение

1. **Автоматическое раскрытие**: Панель фильтров автоматически раскрывается, когда есть активные фильтры
2. **Сохранение в URL**: Все фильтры сохраняются в URL, позволяя делиться отфильтрованными списками
3. **Очистка фильтров**: Кнопка "Сбросить фильтры" удаляет все параметры фильтрации и возвращает к полному списку
4. **Пустое состояние**: При отсутствии результатов показывается соответствующее сообщение

## Доступность

- Все выпадающие списки имеют `<label>` элементы
- Минимальная высота интерактивных элементов - 48px
- Кнопка сброса доступна с клавиатуры
- Summary элемент имеет курсор pointer для понятности

## Совместимость

- Работает на страницах `/trips` и `/archive`
- Совместимо с существующей функцией поиска
- Сохраняет совместимость с мобильными устройствами
- Корректно работает в демо-режиме и локальном режиме

## Известные ограничения

1. **Фильтры отображаются только при наличии минимум 2 поездок** (`all.length > 1`)
2. **Выпадающие списки создаются динамически** на основе данных в поездках
3. **Поездки без дат** игнорируются фильтром по году
4. **Поездки без указанной длительности** (отсутствуют start/end) имеют duration = 0
