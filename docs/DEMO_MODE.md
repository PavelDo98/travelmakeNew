## Как открыть демо-режим

### Способ 1: Через профиль
1. Откройте приложение
2. Перейдите в **Профиль** (иконка 👤)
3. Нажмите **"Открыть деморежим"**

### Способ 2: Прямая ссылка
Добавьте `?demo=1` к URL:
```
https://paveldo98.github.io/travelmakeNew/?demo=1
```

### Способ 3: Локально
```bash
http://127.0.0.1:4173/travelmakeNew/?demo=1
```

## Особенности демо-режима

### ✅ Что работает полностью
- Просмотр всех поездок
- Фильтрация по статусам (предстоящие/архив)
- Все разделы каждой поездки
- Бюджет и финансы
- Вещи с разными статусами
- События и план
- Задачи (выполненные и активные)
- Документы
- Шаблоны
- Раздел "Памятки"

### 🔒 Отдельное хранилище
- Демо-данные хранятся отдельно
- Ваши личные поездки **не затрагиваются**
- Можно свободно экспериментировать
- Выход из демо вернёт к вашим данным

### 📝 Можно редактировать
- Все демо-поездки можно редактировать
- Можно добавлять новые вещи/задачи
- Изменения сохраняются только в демо-режиме
- При новом входе демо-данные сбрасываются

## Реализм

### Географическое разнообразие
- 🇷🇺 Россия: Сочи, Казань, Санкт-Петербург
- 🇹🇷 Турция: Стамбул
- 🇯🇵 Япония: Токио, Киото
- 🇮🇹 Италия: Рим, Позитано
- 🇪🇸 Испания: Барселона

### Временная шкала
- **Прошлое**: 2025 год (Питер)
- **Недавнее прошлое**: май-октябрь 2026 (Барселона, Казань)
- **Сейчас**: ноябрь 2026 (Сочи) ⬅ ТЕКУЩАЯ
- **Ближайшее**: декабрь 2026 (Стамбул)
- **Будущее**: октябрь 2027 (Япония)
- **Дальнее**: апрель 2028 (Италия)

### Разные валюты
- ₽ RUB (рубли) - Россия
- € EUR (евро) - Европа
- ¥ JPY (иены) - Япония
- ₺ TRY (лиры) - Турция

### Разная степень подготовки
- **Полностью готовая**: Сочи (упаковано всё)
- **В процессе**: Стамбул (есть что делать)
- **Раннее планирование**: Япония (основные задачи)
- **Только идея**: Италия (ничего не готово)

## Технические детали

### Файлы
- `js/demo-data.js` - исходные данные
- `js/storage.js` - загрузка демо-режима
- `js/domain.js` - создание поездок

### Структура
```javascript
{
  version: 2,
  revision: 0,
  trips: [
```
